    2. Technical Description

    Splash Screen

    HTML Structure

    • Used <div> containers to structure the splash screen.
    • Added a <h1> tag for the website title and <p> for the mission statement.
    • Included an <img> tag for the background image with CSS styling for full-page coverage.
    • Used <meta> to automatically redirect users after 4 seconds.
    <div class="splash-container"> <div class="splash-content"> <h1>Eco Visionaries</h1> <p>Advocating for environmental sustainability</p> <div class="loading-bar"></div> </div> </div> <meta http-equiv="refresh" content="4;url=home.html">

    CSS Styling

    • Applied position: absolute for a full-screen overlay effect.
    • Used animation for a loading effect.
    • Set text-align: center; and color: white; for better readability.
    • Added a smooth transition effect.
    .splash-container { position: absolute; top: 0; left: 0; width: 100%; height: 100vh; background-image: url('forest-bg.jpg'); background-size: cover; background-position: center; display: flex; justify-content: center; align-items: center; text-align: center; } .splash-content h1 { color: white; font-size: 3rem; text-shadow: 2px 2px 4px rgba(0,0,0,0.5); } .loading-bar { width: 200px; height: 4px; background-color: rgba(255,255,255,0.3); margin: 20px auto; position: relative; overflow: hidden; } .loading-bar:after { content: ''; position: absolute; left: -100%; width: 100%; height: 100%; background-color: white; animation: loading 4s linear forwards; } @keyframes loading { to { left: 0; } }

    5. Challenges and Lessons Learned

    Challenges Encountered

    • Implementing smooth redirection on the splash screen - Initially, the splash screen redirection was abrupt and disrupted user experience. I resolved this by adding a loading animation that completes simultaneously with the redirect timer.
    • Making the volunteer page visually appealing while maintaining responsiveness - The volunteer cards would overlap on smaller screens. I solved this by implementing a flexible grid system that adjusts based on screen width.
    • Ensuring accessibility - Creating proper contrast between text and background elements while keeping the design aesthetic was challenging. I addressed this by adjusting color values and adding text shadows where needed.

    Lessons Learned

    • Improved understanding of CSS animations and how they can enhance user experience without compromising performance.
    • Better structuring of HTML elements for improved readability and maintenance.
    • Gained experience in designing accessible web pages that work across multiple devices.
    • Learned the importance of planning page layouts before implementation to ensure coherent structure.

    6. Accessibility

    I've implemented the following accessibility features across all my pages:

    Feature Implementation Benefit
    Contrast Ratio Ensured all text has at least a 4.5:1 contrast ratio with its background Improves readability for users with visual impairments
    Semantic HTML Used appropriate tags like <article>, <section>, <nav>, etc. Better screen reader support and content structure
    Image Accessibility Added descriptive alt text to all images Screen readers can communicate image content to visually impaired users
    Keyboard Navigation Ensured all interactive elements are keyboard accessible Users who cannot use a mouse can navigate the site
    Focus Indicators Added visible focus states on interactive elements Helps keyboard users identify their current position

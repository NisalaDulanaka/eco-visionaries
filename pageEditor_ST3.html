    • Challenge: Ensuring that team member names and roles are accessible to screen readers.
    • Solution: Used semantic HTML with table elements and scope attributes for better readability.

    • Challenge: Improving navigation for users with mobility impairments.

    • Challenge: Ensuring that text-heavy content is easy to read for users with dyslexia.
    • Solution: Used a readable sans-serif font and provided an adjustable text size option.

    Challenges and Lessons Learned

    Modular Code is Key

    Using separate CSS files made styling more organized and reusable.

    Planning Before Coding Helps

    Structuring HTML first and then styling in CSS helped in debugging faster.

    Always Test Responsiveness

    Using Chrome DevTools helped identify and fix mobile display issues early.

    Validating Code is Important

    Running validation tests regularly prevents last-minute errors.

    Compliance

    • Compliance with Web Standards: The pages follow Janet web page regulations and general web standards to ensure accessibility and usability.
    • HTML Validation: All pages have been checked using the W3C Validator to ensure proper syntax and structure.
    • CSS Validation: Stylesheets have been tested to comply with CSS validation rules, ensuring consistency across different browsers.
    • Metadata Optimization: Proper meta tags have been used for SEO and improving search engine discoverability.
    • Consistent Navigation: Standardized navigation menus ensure usability and accessibility across all pages.
    • GDPR Compliance: No unnecessary data collection, and user privacy is maintained in accordance with data protection regulations.
